# 🍽️ College Canteen Online Ordering System

This is a web-based application designed to streamline the food ordering process in a college canteen. It allows students and staff to browse a categorized menu, add items to their cart, and place orders efficiently—minimizing queues and wait time.

---

## 🔧 Technologies Used

- **HTML5** – Structure of the web pages  
- **CSS3** – Styling and responsive layout  
- **JavaScript** – Interactivity, cart logic, form handling  
- **Font Awesome** – Icons for UI enhancements  
- **LocalStorage** – Cart state persistence

---

## 📁 Project Structure

| File / Folder        | Description |
|----------------------|-------------|
| `index.html`         | Landing/home page with project overview and CTA |
| `menu.html`          | Main ordering page with menu, cart, and checkout |
| `login.html`         | Login form for returning users |
| `signup.html`        | Registration page for new users |
| `about.html`         | Informational page about the canteen |
| `styles.css`         | All global and page-specific styling |
| `script.js`          | Main JS logic for cart, menu, modal, etc. |
| `copy.js`            | Backup or test version of script.js |
| `Images/`            | Folder containing food item images (not included here) |

---

## ✨ Key Features

- 📦 Add items to cart with live quantity updates  
- 💰 Automatic calculation of subtotal, tax, and total  
- 🧾 Order summary modal with student details  
- 🔐 Login and registration forms with validation  
- 🏠 Navigation with Home and Cart icons  
- 📱 Fully responsive for mobile and desktop views
